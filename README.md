Title ID file generator for frontends

# Link

[PS3 HTML link](https://jetup13.github.io/ps3titleid/ps3.html)

# How-to use

1. Open [link](https://jetup13.github.io/ps3titleid/ps3.html)
2. Search name of game/titleid
3. Select ES-DE (.ps3) or Daijishou (.ps3titleid)
4. Generate zip

# ES-DE

* Unzip files inside `~ROMs/ps3/` folder

# Daijishou 

* Unzip files inside a folder
* Sync folder with Daijishou's PS3 platform
